# Institutional Communication Aggregation & Unified Messaging Hub

A comprehensive messaging platform for academic institutions built with Python Flask and MongoDB.

## Features

- User registration and authentication (Admin, Faculty, Student)
- Notice creation with priority levels (Critical, Important, Normal)
- Read acknowledgment tracking
- Missed notice detection
- Real-time analytics dashboard
- Role-based access control
- Mobile-responsive design

## Usage

1. Register as Admin/Faculty/Student
2. Login with credentials
3. Create notices (Admin/Faculty only)
4. View and acknowledge notices
5. Track analytics (Admin/Faculty only)

## Tech Stack

- Backend: Python Flask
- Database: MongoDB
- Authentication: Flask-Login
- Frontend: Bootstrap 5, FontAwesome
- Security: Werkzeug password hashing
